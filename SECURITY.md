# Seguridad

Este es un repositorio privado. No publiques vulnerabilidades, registros,
credenciales, rutas personales ni archivos de clientes en issues o commits.

## Reporte

1. Abre un borrador privado de GitHub Security Advisory en este repositorio.
2. Indica versión, componente, impacto y pasos mínimos de reproducción.
3. Usa datos sintéticos y elimina tokens, claves, cookies y nombres de equipo.
4. No ejecutes una prueba destructiva ni contra sistemas de terceros.

## Límites de confianza

- MCP, Skills, plugins, hooks y toolchains externos permanecen en cuarentena
  hasta verificar procedencia, licencia, hashes, permisos y comportamiento.
- Ningún secreto debe entrar al repositorio, a los logs o a un artefacto.
- Acciones físicas críticas deben conservar control local e independiente de IA.
- Un hallazgo no se considera reparado hasta incorporar una regresión.

# Alcance real — DORN AI 4.0.0-alpha.3

Esta compilación sigue siendo interna. DORN 5.0 continúa siendo la futura edición pública completa.

## Implementado y verificable

- DORN AI coordina proveedores configurados y modelos locales desde un router automático persistente.
- El modo manual continúa disponible cuando la persona decide activarlo.
- Las acciones sobre proyectos se preparan y muestran en un panel pequeño con «Sí», «No» y un menú para aprobar las siguientes del plan actual.
- La decisión de aprobación no se envía a un modelo ni consume tokens.
- CMD, PowerShell y terminal usan una confirmación local equivalente antes de ejecutar.
- El modo automático ignora DORN Local mientras el archivo del modelo no esté descargado; una instalación sin IA lista orienta a Configuración en vez de enviar al motor inexistente.
- Personalización ofrece 20 paletas completas y una imagen de fondo local sincronizada con DORN AI, Design, Editor, Education, Machine y Studio3D. La imagen se valida, permanece en este computador y admite ajuste, intensidad y desenfoque.
- El pie del menú incluye un acceso visual mínimo al servidor oficial de Discord; abre únicamente la invitación fijada en el navegador del sistema.
- DORN puede dictar texto, escuchar una orden con palabra de activación y leer respuestas mediante las voces locales de Windows.
- Una conexión de imagen dedicada puede generar una imagen, mostrarla en la conversación y preparar su guardado recuperable dentro del proyecto.
- «Crear o conectar proyecto» puede crear una carpeta segura con el nombre indicado.
- DORN Education incluye diagnóstico inicial, rutas de estudio, práctica M1 propia y corrector para ocho clavijeros PAES Admisión 2026.
- Los PDF entregados contienen respuestas y tablas de puntaje, no enunciados. Por eso no se presentan como un banco oficial de preguntas.
- DORN Machine sólo admite futuros productos físicos publicados y firmados por DORN. Actualmente hay cero.
- DORN Design, Education, Machine y Editor tienen ventana, proceso, acceso e identidad visual propios, compartiendo configuración autorizada con DORN AI.
- El instalador nativo permite elegir accesos independientes para los productos. DORN AI se instala siempre; en esta alpha los productos todavía comparten el mismo `app.asar`, por lo que desmarcarlos no elimina su código del núcleo.
- El selector `proyecto` vincula internamente conversación, identificador, ruta real, permisos y protocolo de herramientas. El texto posterior define qué hacer y la vinculación determina dónde hacerlo sin convertir la ruta oculta en un mensaje del usuario.
- El Catálogo IA incorpora 984 nombres únicos de la Enciclopedia Mundial aportada al proyecto, indexados por A-Z, empresa, familia, categoría y modalidad.
- Las fichas de enciclopedia se marcan «Por verificar» y permanecen separadas de descargas locales y conectores API reales.
- Configuración usa un único Centro DORN grande; Conexiones permite crear, editar, probar, consultar modelos y eliminar APIs o servidores.
- Las fichas tienen identidad visual estable. El paquete incluye 17 recursos de empresa importados desde Simple Icons 16.28.0 y usa avatares DORN cuando no existe un activo autorizado dentro del proyecto.
